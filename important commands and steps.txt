note : 

1. Database credentials — backend/src/main/resources/application.properties

spring.datasource.url=jdbc:mysql://localhost:3306/devops_practice_db
spring.datasource.username=root
spring.datasource.password=root
2. Frontend → Backend — frontend/src/App.js

const API_URL = process.env.REACT_APP_API_URL || 'http://localhost:8080/api';
React calls http://localhost:8080/api/items, backend handles it.

3. Backend → Database — Spring Boot reads application.properties, connects to MySQL with the credentials above.

The flow:

Browser → React (port 3000) → calls → Backend (port 8080) → queries → MySQL (port 3306)
To change credentials:

Edit application.properties for DB user/password
Edit App.js for API URL
For environment variables at runtime: DB_URL=jdbc:mysql://... mvn spring-boot:run
